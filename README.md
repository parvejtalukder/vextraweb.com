# VextraWeb – Full-Stack Agency App

**VextraWeb** is a modern full-stack web application for a digital technology and reputation management company, founded by **Jakaria Hossain Jusef** and **Parvej Husen Talukder**. The site showcases the company's services, portfolio, pricing and company information in a **fast, scalable, responsive interface**, ready for web and mobile.

---

## Features

- **Hero section** with *Fast Web & Smart Solutions* tagline and "Free Consult" CTA
- **Full page set** — Home, Services, About, Pricing, Contact, Free Consultation + 4 legal pages
- **Services overview**: Web Application Development, E-commerce Solutions, Digital Reputation Management, Content & Media Platforms, Digital Marketing & Publishing
- **Project showcase**: Client logos & portfolio items
- **Interactive contact forms** — open a pre-filled email to `mail.vextraweb@gmail.com` (no backend required)
- **WhatsApp floating button** + phone/email/WhatsApp contacts (phone: **+8801540307370**)
- **Responsive design** — optimized for desktop, tablet, and mobile
- **Legal pages**: Disclaimer, Terms of Use, Privacy Policy, Cookie Policy
- **Animations & polish**: GSAP + Lenis smooth scroll, tech-stack marquee, Swiper service carousel, client reviews
- **Scroll restoration** across route navigation

## Tech Stack

- Vite + React 19 (react-router v7)
- Tailwind CSS v4 + daisyUI + shadcn-style ui components
- GSAP, Lenis, Swiper, Motion, lucide-react

## Commands

```bash
npm install   # install dependencies
npm run dev   # start dev server
npm run build # production build
npm run lint  # ESLint
npm run preview # preview production build
```
